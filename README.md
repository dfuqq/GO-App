# Первое приложение-гид по Сургуту

**🏙️ Уникальный проект с отобранной вручную информацией обо всех заведениях и интересных местах города.**

### Особенности:

- 📍 _Простой интерфейс с категоризацией заведений и мест_
- 🎛️ _Фильтрация для нахождения "того самого" места для посещения_
- 🗺️ _Яндекс.Карты для поиска и возможности проложить маршрут_
- ℹ️ _Вся нужная информация: адреса, цены, рабочие часы, специальные возможности (велопарковки, паркинг и т.п.)_
- 🖼️ _~95% покрытия мест изображениями_

### Стек

- **React + TypeScript**
- **Next**
- **PostgreSQL + ORM Prisma**
- **VKUI**
- **Deploy: Vercel**

<br>

# ⚠️

#### Проект был написан впервые в 2020 году. <br> Некоторая информация, представленная в нём, является устаревшей и служит лишь для ознакомления. <br> Вся информация была взята из сети Интернет и социальных сетей официальных представителей.

# The first application-guide to Surgut

**🏙️ A unique project with manually selected information about all institutions and interesting places of the city.**

### Features:

- 📍 _Simple interface with categorization of institutions and places_
- 🎛️ _Filtration to find "that" place to visit_
- 🗺️ _Yandex.Maps for search and the ability to plot a route_
- ℹ️ _All the necessary information: addresses, prices, working hours, special features (bicycle parking, parking, etc.)_
- 🖼️ _~95% coverage of places with images_

### Stack

- **React + TypeScript**
- **Next**
- **PostgreSQL + ORM Prisma**
- **VKUI**
- **Deploy: Vercel**

<br>

# ⚠️

#### The project was written for the first time in 2020. <br> Some of the information presented in it is outdated and is for Internet and social networks of official representatives.
